Descripción

Práctica enfocada en el uso y manipulación de cadenas de caracteres (String) en Java mediante dos programas.

1. Psicólogo (Psicologo.java)

Simula una conversación entre un psicólogo y un paciente, utilizando las respuestas del usuario para generar preguntas.

2. RFC (RFC.java)

Genera una clave RFC simplificada a partir del nombre completo y la fecha de nacimiento del usuario.
